## 🔒 Vulnerabilities & Security

- **[SurrealDB: Arbitrary File Read via DEFINE ANALYZER mapper()](https://github.com/advisories/GHSA-cc8f-fcx3-gpjr)** — `High`
  - SurrealQL の `DEFINE ANALYZER` のマッパーフィルタを悪用して、サーバー上の任意ファイルを読み取れる脆弱性（Jun 19公開）。Rust製DBで採用増加中のため要確認。修正バージョンは各アドバイザリ詳細ページで確認を。

- **[MessagePack for Python: Out-of-bounds Read on Unpacker Reuse After Caught Error](https://github.com/advisories/GHSA-6v7p-g79w-8964)** — `High`
  - Python `msgpack` (pip) でエラー補足後にUnpackerを再利用するとOOB読み取り/クラッシュが発生（Jun 19公開）。データシリアライズに広く使われるライブラリだけに影響範囲が広い。最新版へのアップデートを推奨。

- **[Gogs: Cross-Site Scripting (XSS)](https://github.com/advisories?query=Gogs)** — `High`
  - Goで実装された自己ホスト型GitサービスGogs（Go製）にXSS脆弱性（Jun 19公開）。セルフホストGitインスタンスを運用中の場合は要確認。

- **[chisel: ACL Bypass via Post-Handshake SSH Channel Data Injection](https://pkg.go.dev/vuln/GO-2026-5054)**
  - GoのリバースプロキシツールchiselにSSHポストハンドシェイク後のチャネルデータインジェクションによるACLバイパス（Jun 16公開）。内部ネットワーク越えに使っている場合は要確認。
