## 🔒 Vulnerabilities & Security
- **[RUSTSEC-2026-0187: `lopdf` — Stack overflow via deeply nested PDF objects](https://rustsec.org/advisories/RUSTSEC-2026-0187.html)** — `High`
  - 深くネストした PDF オブジェクトをパースするとスタックオーバーフローで DoS。信頼できない PDF を `lopdf` で処理しているサービスは要更新。
- **[RUSTSEC-2026-0185: `quinn-proto` — Remote memory exhaustion](https://rustsec.org/advisories/RUSTSEC-2026-0185.html)** — `High`
  - 順序外ストリームの再構成が無制限でメモリを食う。QUIC（quinn ベース）を使うサーバーはリモートからのメモリ枯渇 DoS に晒される。修正版へ。
- **[Incus — multiple critical issues](https://github.com/advisories)** (Go)** — `Critical / CVE-2026-48769, -48755, -48753`
  - コンテナ/VM 管理 Incus に複数の致命的欠陥：信頼イメージハッシュ経由の任意ファイル書き込み、バックアップ圧縮での引数インジェクション、S3 マルチパートアップロードでのパストラバーサル。マルチテナント環境では即時パッチ推奨。
- **[Fluentd — RCE via `${tag}` placeholder arbitrary file write](https://github.com/advisories)** (RubyGems)** — `Critical / CVE-2026-44024`
  - ログ収集の Fluentd で `${tag}` プレースホルダ経由の任意ファイル書き込みから RCE。広く使われる基盤コンポーネントのため影響範囲が大きい。
- **[Nezha — Pre-auth path traversal leaks `jwt_secret_key`](https://github.com/advisories)** (Go)** — `Critical / CVE-2026-53519`
  - 監視ツール Nezha のダッシュボードで認証前パストラバーサル（`/dashboard..` プレフィックス混同）により JWT 秘密鍵が漏洩。併せてテナント横断のターミナル/ファイルマネージャ乗っ取り（GHSA-q6xx-5vr8-p898）も。公開インスタンスは要確認。
