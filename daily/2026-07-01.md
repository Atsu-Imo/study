## 🔒 Vulnerabilities & Security
- **[SimpleHelp — OIDC Authentication Bypass](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)** — `Exploited (KEV) / CVE-2026-48558`
  - OIDC フローで ID トークンを暗号署名検証せずに受理し、認証済みセッションを奪取可能。リモート管理ツールは侵入起点になりやすく KEV 入り＝実際に悪用中。使用中なら最優先でパッチ。
- **[PTC Windchill / FlexPLM — Improper Input Validation RCE](https://www.cisa.gov/known-exploited-vulnerabilities-catalog)** — `Exploited (KEV) / CVE-2026-12569`
  - 入力検証不備により未認証リモートで任意コード実行。製造業の PLM 基盤が対象で、内部ネットに露出していれば影響大。KEV 入りにつき即時対応対象。
- **[RUSTSEC-2026-0189: `rmcp` — DNS rebinding in Streamable HTTP server transport](https://rustsec.org/advisories/RUSTSEC-2026-0189.html)** — `Warning`
  - 公式 Rust MCP SDK の HTTP サーバトランスポートに DNS リバインディング脆弱性。ローカルで動く MCP サーバがブラウザ経由で外部から叩かれ得る。MCP サーバを自作/運用しているなら要確認。
- **[RUSTSEC-2026-0190: `anyhow` — Unsoundness in `Error::downcast_mut()`](https://rustsec.org/advisories/RUSTSEC-2026-0190.html)** — `Info`
  - 極めて広く使われるエラー処理クレートの unsoundness。`downcast_mut()` 経由で未定義動作を招く可能性。直接の攻撃経路は限定的だが依存が深いので更新推奨。
- **[RUSTSEC-2026-0193: `ammonia` — mXSS via MathML `annotation-xml`](https://rustsec.org/advisories/RUSTSEC-2026-0193.html)** — `Info`
  - HTML サニタイザ ammonia で MathML のエンコーディング処理を悪用した mutation XSS。ユーザー入力 HTML を ammonia で消毒しているサービスは XSS 回避のため更新を。
