## 🔒 Vulnerabilities & Security
- **[Januscape: Guest-to-Host Escape in KVM/x86](https://github.com/V4bel/Januscape)** — `CVE-2026-53359 / Critical (UAF)` ＜発見層／HN・lobste.rs＞
  - KVM/x86 の shadow MMU エミュレーションにある **use-after-free**。ゲストVMからホストカーネルのシャドウページテーブルを破壊し、ホスト権限でのRCEやホストパニックに至る。commit 2032a93d（2010/08）〜81ccda30（2026/06）と**約16年**存在。Intel/AMD 両対応の初の guest→host エスケープ実証で、マルチテナント／ネスト仮想化のクラウド基盤に直撃。ホストカーネルのパッチ適用状況を要確認。
- **[cilium — Local Envoy admin socket access enables information disclosure and disruption](https://github.com/advisories)** (Go) — `CVE-2026-49445 / Critical`
  - Cilium の Envoy admin ソケットへのローカルアクセスで情報漏洩・通信妨害が可能。Kubernetes CNI に Cilium を使っている環境は該当バージョンの確認を。
- **[langroid — eval() sandbox escape to RCE + Cypher/DB injection](https://github.com/advisories)** (pip) — `CVE-2026-54769 / -54760 / -55615・Critical`
  - LLM エージェントフレームワーク langroid で、`eval()` サンドボックスの回避によるRCE、LLM生成 Cypher/DBクエリの無検証実行によるインジェクションが連鎖。**LLM出力を実行系に渡す設計の典型的な落とし穴**で、自作エージェントの防御設計の反面教師になる。
- **[RUSTSEC-2026-0204: crossbeam-epoch — invalid pointer deref in `fmt::Pointer` for `Atomic`/`Shared`](https://rustsec.org/advisories/RUSTSEC-2026-0204.html)** (Rust) — `Critical (listing)`
  - `Atomic::null()`/`Shared::null()` を `Display`（`{}`）整形するとヌルポインタを参照してクラッシュ。影響は 0.9.0〜0.9.19、**0.9.20 で修正**。`Debug`（`{:?}`）は非該当で、実害はデバッグ整形時のDoS程度。依存が広いクレートなので `cargo update` 推奨。
- **[RUSTSEC-2026-0202: cxx — `let_cxx_string!` uses uninitialized value](https://rustsec.org/advisories/)** (Rust) — `Info`
  - 例外安全性違反により `let_cxx_string!` が未初期化値を使う可能性。C++相互運用で cxx を使うコードは要確認。
- **CISA KEV**: 7/7 時点で SharePoint RCE（CVE-2026-45659, 7/1追加）以降の新規確認済み追加はなし。
