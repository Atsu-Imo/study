## 🔒 Vulnerabilities & Security
- **[aws-smithy-http-server — unauthenticated Slowloris DoS in `serve()`](https://github.com/advisories/GHSA-jvxp-qmx7-gjpx)** (crates.io / Rust) — `CVE-2026-16756 / CVSS 8.7 High`
  - デフォルトサーバ設定に接続タイムアウト・ヘッダ読み込みタイムアウト・同時接続数上限がなく、未完了の部分リクエストを大量に張るだけでソケットとタスクを枯渇させられる。
  - 影響: `<= 0.66.4` → **0.66.5 で修正**。回避策なし、アップグレード必須。Smithy 生成の Rust サーバ（AWS SDK 系ツール含む）を自前でホストしている場合は最優先。フォーク／派生実装も要確認。
- **[etcd — Watch API authorization bypass ＆ unbounded TLS handshake goroutines](https://github.com/advisories/GHSA-xg4h-6gfc-h4m8)** (Go / go.etcd.io/etcd) — `CVSS 7.1 High`（＋[GHSA-6vch-q96h-7gc3](https://github.com/advisories/GHSA-6vch-q96h-7gc3) High）
  - 単一キーの READ 権限しか持たないユーザが `clientv3.WithFromKey()` を使うと、そのキー以降（辞書順）の**全キーの watch イベントを受信できる**。Range/Get・DeleteRange は正しく制限されているため、Watch のみの認可漏れ。
  - 影響: `< 3.5.33` / `3.6.0〜< 3.6.14` / `3.7.0-alpha.0〜< 3.7.1`。**認証を有効にしているクラスタのみ**が対象（無認証クラスタは元々素通し）。Kubernetes の裏側で etcd を触る場合は READ 権限付与の棚卸しとクライアントポートの網制限を。
