# drill-02 メモ

## 詰まったところ（Claude 記録 / 2026-08-14）

段階ヒントで解けず、実装を出したもの。

- **レスポンスボディの読み切りと Close の置き場所**（要件21）。
  `switch` の各 case で閉じようとすると4箇所になって漏れる、という構造の問題。
  「送信エラーを switch の外に出す → 読んで閉じる → 分類する」の順序に気づけば1箇所で済む。

段階ヒントで解けたが時間がかかったもの。

- `switch` の case が自動で下に落ちない（`fallthrough` がない）ため、空の case が
  「何もせず抜ける」になっていた
- `else` の枝の中で `dd :=` を書いてしまい、外側の `dd` が 0 のままだった（シャドーイング）
- `%w` で包む対象が nil のまま最終行に到達していた（失敗の記録が1経路にしかなかった）
- `context.WithCancel` と `ctx.Err()` の役割の取り違え

## 課題の設計への指摘（ユーザー / 2026-08-14）

- 要件22（ゼロ値に既定値を入れる）は、本来アプリケーションの初期化段階でやるべきで、
  リクエスト実行時のスコープでやることではない
- リトライは API 1本ごとに実装するものではなく、横断的な層に置くもの。
  1本の中に閉じ込めた形で書かされると意図がつかみにくい
